\chapter{Complexity Classes}

What is the best time complexity for a problem? When can we hope 
to come up with a \emph{fast} algorithm? This is exactly the point of defining complexity classes. While 
the classes themselves are defined rigorously, there are some very 
important\footnote{Such as the classic question of $\classP \neq \NP \dots$} statements which 
have not yet been proved -- they remain open problems! In practice, however, we have conjectures which we believe 
to be true for now$\dots$

\section{Decision Problems}
Complexity classes are traditionally defined using \emph{decision problems}. A decision problem is a 
computational problem whose answer is either \texttt{YES} or \texttt{NO}.

\begin{itemize}
\item Given a graph $G$, is $G$ connected?
\item Given an integer $m$, is $m$ prime?
\item Given a graph $G$ and an integer $k$, does $G$ contain a clique\footnote{Refer \autoref{clique}} of 
size at least $k$?
\end{itemize}

Although not all computational tasks are naturally decision problems, most can be 
reformulated as one. For example, the largest clique in a graph can be reformulated\footnote{Some 
of these reformulations are called \emph{polynomial time reductions} which will be properly discussed later.} as 
"is there a clique of size at least $k$ in $G$?". 


\section{P}

The class $\classP$ consists of all decision problems that can be solved by a 
deterministic algorithm in at most polynomial time. Let $Q$ be a decision problem and $T(Q)$ be the best
time complexity\footnote{This time complexity is in terms of the input length 
and not the input number itself -- a number $n$ when taken as input is represented by 
a bit string of size $m=\Theta(\log n)$. So an algorithm which takes $O(n)$ time will be considered 
as an exponential time algorithm since $\Theta(n) = \Theta(2^m)$. This is why the normal method of 
trying all numbers from $1$ to $\sqrt n$ will not prove that primality testing of a number is in $P$.} 
of a deterministic algorithm for $Q$. Then $T(Q) \le \Theta(n^c)$ for some constant $c\ge1$ 
implies $Q \in \classP$.

\[
\classP \; = \; \bigcup_{c\ge1} \;\; \{Q: T(Q) \le \Theta(n^c)\}
\]

\begin{tabular}{|c|c|c|c|c|}
\hline
\textbf{Decision Problem(Q)} & \textbf{Algorithm} & \textbf{Input} & \textbf{Input Size} & \textbf{Runtime (T(Q))} \\
\hline
Primality Test & AKS & Integer & $m=\Theta(\log_2 n)$  & $\Theta(m^{12})$ \\
Graph Connectivity & BFS & Adjacency Matrix & $n=|V|\times|V|$ & $\Theta(n)$ \\
\hline

\end{center}

\section{NP}

The class $NP$ consists of all decision problems whose answer when \texttt{YES} can be verified in polynomial 
time. The algorithm which solved the problem can output a \emph{certificate} along with \texttt{YES} -- this 
certificate is information which can be used to verify in polynomial time that the answer is indeed \texttt{YES}. 

\begin{center}
\begin{tabular}{|c|c|c|}
\hline
\textbf{Decision Problem (Q)} & \textbf{Certificate} & \textbf{Verification Time} \\
\hline
Clique of size $k$ & Set of $k$ vertices & $\Theta(k^2)$ \\

Graph Coloring of $k$ colors & Vertex\;:\;Color mapping & $\Theta(V+E)$ \\
\hline
\end{tabular}
\end{center}

An obvious conclusion from the definition of $\NP$ is that $\classP\subseteq \NP$ because any problem that can be 
solved in polynomial time can also be verified in polynomial time by giving the problem itself as a 
certificate and the verification procedure is the solution itself.

\section*{$\coNP$}

The class $\coNP$ contains complements of problems in $\NP$. In this class of problems, the answer \texttt{NO} has a 
certificate verifiable in polynomial time. For example, the complement of the clique problem asks 
whether every clique in the graph has size at most $k-1$. The answer \texttt{NO} can be accompanied by a 
certificate which is the set of vertices forming a clique of size at least $k$.\\

\noindent An obvious conclusion is that any algorithm that solves an $\NP$ problem also 
immediately solves the corresponding $\coNP$ problem by just flipping the answer from \texttt{YES} to \texttt{NO} 
and vice versa but the catch being it may not be able to produce a certificate for \texttt{NO} answer. 

\section{Polynomial-Time Reductions}

To compare the difficulty of computational problems, we use the idea of \emph{polynomial-time reductions}. A 
problem $A$ is polynomial-time reducible to a problem $B$ if we can convert $A$ to $B$ in polynomial time.\\

This is denoted by $A \le_p B$. This means that if we can solve $B$ in polynomial time, then we can 
also solve $A$ in polynomial time. The notation suggests $B$ is harder than $A$ and one might find 
this confusing because we "reduced" $A$ to $B$ so shouldn't $B$ be easier? Think of a reduction as a 
one-way procedure that converts $A$ to a \emph{particular} case of $B$. Solving the 
general case of a problem is at least as hard as solving the particular case. That is why $B$ is 
at least as hard as $A$ under polynomial time reduction.\\

The operator $\le_p$ is a partial order\footnote{Refer \autoref{partial_orders}}. We can also 
define $=_p$ as $A=_pB$ iff $A\le_pB$ and $B\le_pA$. This can be used to induce equivalence 
classes\footnote{Refer \autoref{equivalence_classes}} within the complexity classes like $\NPcomp$ 
which is the ``biggest'' equivalence class in $\NP$.

\section{NP-Complete}
$\NPcomp$ consists of those $\NP$ problems which are at least as hard as \emph{every} problem in $\NP$. 
For an $L$ in $\NPcomp$, every problem in $\NP$ can be polynomially reduced to $L$.

\[
\NPcomp \; = \; \{L: Q \le_p L \quad \forall \; Q \in \NP\}
\]

\section{RP}

A decision problem belongs to $\RP$ if there exists a randomised polynomial-time algorithm with input size $n$ 
satisfying the following properties:

\begin{itemize}
\item If the correct answer is \texttt{NO}, the algorithm always outputs \texttt{NO}.
\item If the correct answer is \texttt{YES}, the algorithm outputs \texttt{YES} with 
probability at least $\frac{1}{n^c}$, $c>0$.
\end{itemize}

Consider an algorithm as mentioned above -- it outputs \texttt{YES} in the case where correct answer is 
\texttt{YES} with probability $p \ge \frac{1}{n^c}$. Run it $k$ times and answer \texttt{YES} 
if it occurs even once in the $k$ runs otherwise answer \texttt{NO}. This new algorithm has the 
same properties as the original algorithm except $p$ is replaced by $1-(1-p)^k$. So if an 
algorithm has $p \ge \frac{1}{n^c}$, then for $k=n^c$ the probability will be more than $1-\frac{1}{e}$. 

\[
(1-\frac{1}{n^c})^{n^c} \le \frac{1}{e} \implies 1-(1-\frac{1}{n^c})^{n^c} \ge 1-\frac{1}{e}
\]

\vspace{1em}
As long as $k$ is polynomial in the input size, the overall algorithm is also polynomial time.
The point of having a lower bound $\frac{1}{n^c}$ is that we should be able to 
achieve any desired correctness probability by repeating the algorithm a polynomial number of times
times -- this may not be possible if our criterion is something like $\frac{1}{2^n}$. Once we get a 
lower bound of $1-\frac{1}{e}$, we can do a constant number of repetitions (still keeping the 
algorithm overall polynomial) to achieve a probability which is as close to 1 
as we desire. 

\section*{$\coRP$}
A problem belongs to $\coRP$ if there exists a randomised polynomial-time algorithm satisfying the 
following properties:

\begin{itemize}
\item If the correct answer is \texttt{YES}, the algorithm always outputs \texttt{YES}.
\item If the correct answer is \texttt{NO}, the algorithm outputs \texttt{NO} with probability at 
least $\frac{1}{n^c}$, $c>0$.
\end{itemize}

To clarify, when we say randomised polynomial time algorithm, we mean an algorithm which makes 
random choices but whose time complexity is polynomial in the input size. The relevant time complexity here is 
the actual worst-case time complexity and \textbf{not} the expected time complexity.

\section{ZPP}
A decision problem belongs to $\ZPP$ if there exists a randomized algorithm that has the following properties:

\begin{itemize}
\item It outputs the correct answer with probability $1$.
\item Expected time complexity is polynomial in the input size.
\end{itemize}

\section{BPP}
A decision problem belongs to $\BPP$ if there exists a randomized polynomial-time algorithm 
whose probability of producing the correct answer is at least $\frac{1}{n^c}$, where $c>0$.

\section{Problems}

\begin{enumerate}

\item[\textbf{1}]
Solving an $\NPcomp$ problem in polynomial time is considered extremely difficult (if not impossible).
Let $C$ be the event that a single $\NPcomp$ problem is solved in polynomial time.

\begin{enumerate}[label=\textbf{(\alph*)}]
\item Show that $C \implies \classP = \NP = \NPcomp$
\item Show that $\classP \subseteq \left(\coNP \cap \NP\right) \subseteq \NP$ and thus show $C \implies \NP = \coNP$
\end{enumerate}

\item[\textbf{2}]
Modern cryptography relies on the existence of one-way functions. One-way functions are functions which 
are computable in polynomial time but not invertible in polynomial time. 

Consider the function $F: \{0,1\}^n \mapsto \{0,1\}^m$

\begin{enumerate}[label=\textbf{(\alph*)}]
\item Show that if $F$ is invertible, $m \ge n$
\item Using the above result, show that if $\classP=\NP$ then $F$ can not be a one-way function by 
reformulating the problem of finding the inverse as a decision problem.
\emph{Hint: Go bit-by-bit.}
\end{enumerate}

\item[\textbf{3}]
\noindent Consider an algorithm \texttt{ALGO} which solves a decision problem $Q \in \ZPP$ with 
runtime $T$ whose expected value is $E$ such that $E \le n^c$ where $c>0$. 
Now consider the algorithm \texttt{TIMED\_ALGO}:

\begin{center}
\begin{minipage}{0.9\linewidth}
\begin{framed}
\begin{Verbatim}

TIMED_ALGO
{
    run ALGO with time limit 2*E
    if time limit exceeded
        return NO
    else 
        return answer of ALGO
}
\end{Verbatim}
\vspace{-4mm}
\end{framed}
\end{minipage}
\end{center}

Let $p$ be the probability that \texttt{TIMED\_ALGO} gives the correct answer.

\begin{enumerate}[label=\textbf{(\alph*)}]
\item Show that $p \ge Pr(T \le 2E)$
\item Use the markov inequality to show that $Pr(T > 2E) \le \frac12$
\item Use the answers to \textbf{(a)} and \textbf{(b)} to show that the problem is solved by \texttt{TIMED\_ALGO} 
with probability at least $\frac{1}{2}$. 
\item Using the result from \textbf{(c)}, show that $Q \in\BPP$. Show that this proof works 
for a general $Q \in \ZPP$, thus proving that $\ZPP \subseteq \BPP$
\item Use a similar setup to show $\ZPP \subseteq \RP \cap \coRP$
\item For a general problem $Z$ in $\RP \cap \coRP$, use its $\RP$ solution and its $\coRP$ solution to create 
a $\ZPP$ solution, thus showing that $\RP \cap \coRP \subseteq \ZPP$. Use this along with \textbf{(e)} to prove that 
$\RP \cap \coRP = \ZPP$
\end{enumerate}

\end{enumerate}
